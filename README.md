# sachi-monitor

Public GitHub Pages dashboard generated from `sachi-web`.

This repo is intentionally simple: it contains only static files that can be
served directly by GitHub Pages. The real code lives in `sachi-web`, and the
private market data plus monitor state live in `sachi-web-data`.

## Related Repositories

```text

rahlyadav/sachi-web-data  private data/state repo
rahlyadav/sachi-monitor   public dashboard repo
```

Local folder names:

```text

trading-web-data  private data/state repo

```

## What Is Public

Everything in this repo is public if GitHub Pages is enabled. The dashboard does
not include the Python strategy code, full OHLC CSV database, full prediction
history, GitHub tokens, or private workflow secrets.

It does publish monitor-visible information such as:

- Symbols.
- Entry and exit dates.
- Entry, latest, and exit prices.
- Active or closed status.
- Returns.
- Strategy labels.
- Chart points used by the dashboard.

Treat anything shown on the page as public.

## Dashboard Sections

The page shows:

- Latest activity: trades added or closed on the latest data date.
- Active trades: currently monitored open trades.
- Closed trades: completed monitor trades.
- All trades: combined monitor view.
- Trade chart: entry-to-latest chart for active trades, and entry-to-exit chart
  for closed trades.

## How It Updates

The scheduled workflow in `sachi-web` builds this repo after fresh data,
prediction, and monitor steps complete.

The normal flow is:

1. `sachi-web` downloads or updates private data.
2. The workflow checks that OHLC data advanced and stock coverage is more than
   `90%`.
3. Predictions are generated.
4. Accepted active predictions are added to the web monitor.
5. Strategy exits are applied to active monitor trades.
6. Static dashboard files are built.
7. This repo is replaced with the generated output and pushed.

The workflow runs Monday-Friday at:

```text
17:11 IST
19:11 IST
```

The later run is a backup for late market-data availability.

## Manual Regeneration

From the local `trading_web` folder:

```bash
python3 scripts/build_pages_site.py
```

Then copy the generated site into this repo:

```bash
rsync -a --delete --exclude .git --exclude .DS_Store --exclude .gitignore public/ ../trading-monitor/
```

After reviewing, commit and push from `trading-monitor`.

## Source Of Truth

This repo is an output artifact. The source of truth is:

```text
sachi-web-data/state/current_monitor.json
sachi-web-data/state/latest_monitor.json
```

If dashboard values look wrong, fix the app logic or private state first, rebuild
the dashboard, then publish the generated files here.
